# DFY Funding

Conversion-led agency site for DFY Funding built on Next.js App Router.

## Stack
- Next.js App Router
- TypeScript
- Local content files
- Tailwind-ready global CSS baseline
- Server Action intake flow

## Run locally

```bash
npm install
npm run dev
```

## Environment

Copy `.env.example` to `.env.local` and set:

* `SITE_URL`
* `INTAKE_WEBHOOK_URL`
* `BOOKING_URL`
